# Nikon D3400 photos

Drop your Instagram shots here as `.jpg`.

They become web paths automatically — a file named `photo-01.jpg` here is
served at `/assets/photos/nikon-d3400/photo-01.jpg`, which is what the
review post references.

## Before uploading

- Resize to ~2000px on the long edge
- Export JPEG at quality ~80
- Strip GPS EXIF if the location is private

Straight-out-of-camera files are 20–40 MB each and will make the page
unusable on mobile.
